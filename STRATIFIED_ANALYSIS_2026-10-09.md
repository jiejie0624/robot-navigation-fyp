# Stratified simulator analysis — 2026-10-09

This report re-aggregates the two 480-row benchmark batches by map family. Ten repeated trials on one map are first reduced to that map's median; the displayed planner metrics are then the median across maps in that family. Thus, the independent-map count is explicit and repeat count is not mistaken for sample size. The family labels follow the simulator's designed scenarios and requested seed-density bands. The grouping is exploratory, and five fixed maps or six deterministic seeds do not represent a broad sample of all rooms.

`D* − A*` values are computed as paired differences within each map/repeat, reduced to a median per map, then summarized by the median across maps. Negative expansion differences mean fewer expanded nodes for D* Lite; positive time differences mean longer measured planning time for D* Lite. `no_route` is shown separately as a single map and is a correctness condition, not a route-navigation difficulty sample.

## Interpretation and limits

In these simulator batches, D* Lite expanded fewer cells in every displayed family-level median, while its family-level median planning time was higher in every family. This is consistent with the total-batch observation that fewer expansions did not translate into lower measured runtime for this implementation. On the hand-designed reachable maps, route length and replanning counts also differed, which illustrates why node expansion, time, and end-to-end behavior need separate reporting.

These summaries are descriptive, not inferential: family sizes are only five or six maps, the layouts are generated by one simulator, and repeated measurements share the same maps and browser session. The no-route group has one map and should not be generalized. See `FAIR_REPLAY_PROTOCOL.md` for a separate controlled planner-replay experiment that fixes update events and query positions.

## Reproducibility

Regenerate the CSV tables using:

```powershell
python analyze_strata.py benchmark-15x15-2026-10-09.csv
python analyze_strata.py benchmark-25x25-2026-10-09.csv
```

The outputs are `benchmark-*-strata-summary.csv`. They report map counts, run counts, correctness/safety counts, map-level metric medians and interquartile ranges, and paired D* Lite-minus-A* differences.
